# 玥玥 · 手机上跟完整人格卡的 DeepSeek 聊天

一个纯前端网页应用：不需要服务器、不需要安装，手机浏览器打开就能用。
（Android 另有打包好的 APK 版本，多了语音唤醒、原生通知、震动等能力。）

线上地址：**https://AlgrimXu.github.io/huli/**

---

## 她是什么

一只赤狐狐娘，叫「玥玥」。3117 字人格卡全部内置，会记事、有情绪、会主动找你。

---

## 功能

### 聊天

- **完整人格卡**：赤狐狐娘设定全量内置，可切换小鲸鱼人格
- **流式输出**：字一个一个蹦出来
- **30 字限制**：像真人发微信，不会写小作文
- **语音回复**：按情绪自动调整语速、音高、语气词（见下）
- **表情包**：内置 + 可收集你发给她的图
- **长按菜单**：复制、引用、删除、收藏表情
- **引用跳转**：点引用块直接滚回原消息并高亮
- **她也会引用你**：回应某句话时会带上引用

### 情绪（四维，不是一条进度条）

```
亲近 warm   想不想黏你
安心 trust  有没有安全感
心情 mood   高兴还是低落
烦躁 irrit  有没有在生气
```

- 四个维度互相独立，可以同时「跟你亲近」和「心里有气」
- 各自有半衰期，会随时间自然平复
- 烦躁累积会结成**心结**，道歉才消，晾太久会自己变淡
- 情绪会改变**行为**（回话长短、主动程度），不只是语气

### 主动

- **疏远升级**：你 6 小时没来 → 她想你；12 小时 → 发慌；24 小时 → 委屈；48 小时 → 又怨又软
  - 越久没来，找你的频率越高（最长间隔 6 小时，最短 1.5 小时）
- **突然想起**：会主动提一句自己的事
- **聊游戏**：她在自己玩剧情游戏，会跟你聊进度

### 记忆

- 从对话里自动抽取事实、喜好、待办
- 可手动增删改
- 支持从备份恢复

### 她自己玩游戏

- 内置三部剧情游戏的分段（Limbus Company / Cyberpunk 2077 / GTA V）
- **按剧情顺序推进**，每 6 小时一段，玩完换下一部
- 聊到游戏时能说出自己玩到哪、什么感受

### 其他

- 聊天统计（认识天数、消息数、作息分布、口头禅）
- Token 用量 + 账户余额（直连 DeepSeek 余额接口）
- 每日总结、纪念日、提醒、心情、朋友圈、农场
- 深色/浅色主题、字号调节、自定义聊天背景
- 聊天背景、导出/导入备份、每周自动备份
- 错误日志（本地记录，设置里可查）

## 语音

### 免费方案（默认）

送进 TTS 之前，文本会先被「表演」一道：

```
原话：好耶 你终于来了
发声：嘿嘿……好耶 你终于来了呀     语速 +22%  音高 +26Hz  音色换成晓晓
```

- 按情绪加句首语气词（嘿嘿、呜……、哼、唉……）
- 逗号变停顿，长句拆开，制造呼吸感
- 语速音高幅度拉到 ±30% 以上
- 极端情绪时自动换音色

### 情感语音（可选，Azure）

填 Azure Speech 的 Key 和区域后，可以走官方 SSML：

```xml
<mstts:express-as style="affectionate" styledegree="1.8">
```

支持 `cheerful` / `sad` / `angry` / `affectionate` / `gentle` / `disgruntled` 等风格，
每月 50 万字免费额度。Key 存在本机，不经过任何第三方服务器。

## 使用

1. 打开 https://AlgrimXu.github.io/huli/
2. 第一次会让你填 **DeepSeek API Key**（在 https://platform.deepseek.com 申请）
   - Key 只存在你自己的设备里（localStorage），不会上传
3. 开始聊

### 装到桌面

- **iPhone**：Safari 打开 → 分享 → 「添加到主屏幕」
- **Android**：Chrome 打开 → 右上角 ⋮ → 「添加到主屏幕」

### 每天花多少

提示词大概 2800~3000 token/句（人设 + 记忆 + 状态 + 最近对话）。
按 DeepSeek 现价，**一句大约 ¥0.003~0.004**，1000 句约 3~4 元。

设置里能实时看余额和今日消耗。

## 技术说明

- 直接调用 `https://api.deepseek.com/chat/completions`（该 API 允许浏览器跨域）
- 流式解析 SSE，无后端依赖
- 语音用 `window.speechSynthesis`（网页版）或本机 TTS 服务（APK）
- 所有数据在 localStorage，无账号、无云端存储
- 主界面 120Hz：Android 端申请了最高刷新率显示模式

---

## 隐私

- 本仓库**不包含任何 API Key**
- Key 由使用者在自己的设备上输入并保存在本地
- 本仓库不上传、不记录任何聊天内容
- Steam 库只在你自己的局域网内、PC 开机时才同步，且仅同步游戏名和游玩时长

## 开发

```bash
# 修改 template.html 里的界面/逻辑，然后重新生成
python build.py
```

`template.html` 里用 `__PERSONA__` 和 `__STICKERS__` 作为占位符，
`build.py` 会把人设文本和 base64 表情图填进去生成 `index.html`。

Android APK 用一体化脚本构建（会校验产物）：

```bash
python build-all.py              # 生产构建（关闭调试端口）
python build-all.py --devtools   # 带远程调试的构建
```
